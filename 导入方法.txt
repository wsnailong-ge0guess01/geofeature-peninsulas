GeoFeature 半岛数据「导入方法」
=================================

项目网页有两套数据源（见源码）：
  1) 内置库模式：网页里的 var FEATURES = [...]（适合几百~几千条，随页面一起加载）
  2) 瓦片模式：设置 var TILES_URL（PMTiles/静态瓦片，适合上万~几十万条）

你交付的两个文件对应两种导入法：

---------------------------------------------------------------
【文件】半岛_可导入数据.csv / 半岛_可导入数据.geojson（14,896 条）
---------------------------------------------------------------

■ 方法 A：导入为「内置库」（最简单，推荐先用这个）
  用脚本把 geojson 合并进网页 FEATURES 数组，生成新网页（不覆盖原文件）。

  步骤：
   1. 把 import_可导入数据.py、半岛_可导入数据.geojson、网页文件放进同一个文件夹（如 D:\待删除）；
   2. 打开 cmd，执行：
        cd /d D:\待删除
        python import_可导入数据.py geo_features_tiles_全球半岛版.html
   3. 生成 geo_features_tiles_全球半岛版_已导入.html，双击打开即生效；
   4. 只想导入「有共识名的」可加参数：
        python import_可导入数据.py geo_features_tiles_全球半岛版.html --only 共识译名
      只导入共识名+音译名：
        python import_可导入数据.py geo_features_tiles_全球半岛版.html --only 共识译名,音译名

  说明：导入后每条都带「名称性质」（共识译名 cs / 音译名 tl / 待补译名 un），
        网页右上面板和图鉴会按性质显示。

■ 方法 B：导入为「瓦片」（数据量大时用，最省内存）
   把 geojson 烘焙成 PMTiles，再让网页走瓦片模式：
   1. 安装 tippecanoe 或使用项目自带 tools/bake_tiles.sh；
      例如：
        tippecanoe -o features.pmtiles -l features -zg --drop-densest-as-needed 半岛_可导入数据.geojson
   2. 把 features.pmtiles 放到网页同目录；
   3. 打开网页源码，把这一行：
        var TILES_URL = '';
      改成：
        var TILES_URL = './features.pmtiles';
   4. 保存刷新，网页即从瓦片按视野加载。

---------------------------------------------------------------
【文件】半岛_离线数据.csv / 半岛_离线数据.json（1,565 条，内置库自身）
---------------------------------------------------------------
这两个是「网页内置的那 1400+ 条半岛」的导出，用于替换/回填内置库，不算“导入”。
- 半岛_离线数据.json 就是 FEATURES 兼容格式，可直接替换网页 var FEATURES = [...] 的内容；
- 半岛_离线数据.csv 为表格版，便于查看/编辑。

---------------------------------------------------------------
名称性质字段对照
---------------------------------------------------------------
  网页 src 码   名称性质      含义
  cs            共识译名      采用公开通用中文译名
  tl            音译名        暂无公开共识译名，按原名音译
  un            待补译名      暂无中文名，待补
